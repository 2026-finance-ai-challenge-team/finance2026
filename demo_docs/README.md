# demo_docs — 데모·테스트용 합성 문서

문서 분류 모듈을 누구나 바로 돌려볼 수 있게 하는 **합성 샘플 모음**이다.
심사자·팀원이 자기 개인문서를 꺼낼 필요 없이 이 폴더만으로 전체 흐름을 확인할 수 있다.

## 규칙 — 이것만 지키면 된다

| | |
|---|---|
| 올려도 되는 것 | 지어낸 이름·주소·번호로 만든 **합성 문서** |
| **올리면 안 되는 것** | 실제 개인정보가 든 문서. 본인 것이라도 안 된다 |

실제 문서로 시험할 때는 `.gitignore`에 등록한 개인 로컬 폴더를 쓴다.
`AGENTS.md` 개인정보 원칙과 `CLAUDE.md`의 "테스트·샘플은 합성 데이터만"이 근거다.

각 PDF 하단에는 실제 증명서가 아니라는 문구가 인쇄된다.

## 지금 들어 있는 것

| 파일 | 문서 종류 | 왜 이걸 넣었나 |
|---|---|---|
| `합성_주민등록표등본.pdf` | 주민등록표 등본 | 가장 많이 쓰이는 공문서. 제목·앵커·문서확인번호가 모두 있다 |
| `합성_전기요금청구서.pdf` | 공공요금 고지서 | MVP 업무에서 **필수**인데 실물 표본이 없던 종류 |
| `합성_재직증명서.pdf` | 재직증명서 | **사문서**. 서식이 회사마다 달라 분류가 가장 어려운 사례 |

## 다시 만들기

```bash
finance/Scripts/python.exe demo_docs/make_samples.py
```

`make_samples.py`가 reportlab 내장 한국어 폰트로 생성한다. 별도 폰트 파일이 필요 없다.
문서 종류를 늘리려면 함수를 하나 더 쓰고 `main()`에 추가한다.

## 돌려보기

```bash
# 텍스트 PDF라 OCR을 호출하지 않는다 (API 사용량 0)
finance/Scripts/python.exe -m modules.doc_classify.cli demo_docs --no-ocr --report
```

현재 결과:

```
[O] 합성_주민등록표등본.pdf    주민등록표 등본           0.99   관련
[O] 합성_전기요금청구서.pdf    공공요금 고지서·납부확인서  0.95   관련
[-] 합성_재직증명서.pdf        재직증명서                0.80   이번 업무에는 불필요
OCR 호출: 0회
```

## 한계

여기 문서는 **텍스트 레이어가 있는 PDF**다. 실제 사용자가 올릴 스캔본·사진과 달리
OCR 경로를 태우지 않는다. 사진 경로를 검증하려면 이 PDF를 인쇄해서 촬영한 이미지가
필요하고, 그건 합성이라도 촬영본이라 별도로 준비한다.
